# Research records

Dated, word-for-word records of the reviews, investigations, and discussions
that shaped the design. They exist so that nothing important lives only in a
chat session or an assistant's memory.

These files are **history, not specification**. Decisions drawn from them
are written into `docs/ROADMAP.md`, `docs/USE-CASES.md`,
`docs/ARCHITECTURE.md`, `docs/TEST-DATA.md`, `docs/RELEASING.md`, and (as they
are written) the ADRs and L1/L2/L3 requirements; where a record and those
documents differ, those documents govern. Records are not edited after the
fact except to correct a transcription error; a later finding goes in a new,
dated record.
